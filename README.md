# Euler Angles 3D Visualizer

Interactive 3D visualization of Euler angles using the convention

**R = Rz(ψ) Ry(θ) Rx(φ)**

The interface shows the initial reference frame and applies the rotations one at a time:

1. ψ (psi): rotation about Z
2. θ (theta): rotation about the new Y axis
3. φ (phi): rotation about the newest X axis

Use the step controls, sliders, orbit camera, and animation mode to inspect how the reference frame changes at every stage.

## Run

Open `index.html` directly, or deploy the repository with GitHub Pages.
